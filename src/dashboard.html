데이터 연결

각 PC·서버에서 claude-usage-collect.py를 돌려 만든 JSON을 여기에 끌어다 놓거나 클릭해서 선택하세요.

수집: python3 claude-usage-collect.py --machine "집-데스크탑" · 머신 id가 같은 파일을 다시 넣으면 최신 스냅샷으로 교체됩니다.

수치는 Claude Code가 ~/.claude/projects의 세션 트랜스크립트에 직접 기록한 토큰 값을 합산한 것입니다. Anthropic의 청구·한도 기준 수치가 아니며, 트랜스크립트가 정리·삭제된 기간은 집계에서 빠집니다.
